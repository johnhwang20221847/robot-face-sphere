# Robot Face Sphere

졸업전시용 인터랙티브 로봇 표정 모션그래픽 (구형 얼굴 버전). 노트북 카메라로 감상자를 인식해 시선으로 따라가고, 감상자의 움직임에 따라 표정과 배경색이 바뀝니다.

**실행:** <https://johnhwang20221847.github.io/robot-face-sphere/> 를 Chrome으로 열고 카메라 권한을 허용하세요. (로컬에서는 `시작.command` 더블클릭)

| 상황 | 흐름 |
|---|---|
| 1 | 입장 → 멈춰 섬 → 환호 (컨페티) |
| 2 | 계속 움직임 → 걱정(노랑) → 멈춤 → 두리번거림 |
| 3 | 계속 움직임 → 걱정 → 화남(빨강) → 멈춤 → 두리번거림 |
| 4 | 계속 움직임 → 걱정 → 화남 → 화면을 가득 채울 때까지 커짐 |

**단축키:** `D` 디버그 화면 · `M` 좌우 반전 · `F` 전체화면 · `1~5` 상태 테스트 · `6~9` 대기 연기 미리보기 · `0` 자동

사람 인식: [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) (오프라인 동작을 위해 라이브러리·모델 포함)
