# Robot Face Sphere

졸업전시용 인터랙티브 로봇 표정 모션그래픽 (구형 얼굴 버전). 노트북 카메라로 감상자를 인식해 시선으로 따라가고, 감상자의 움직임에 따라 표정이 바뀝니다. (배경색은 파란색으로 고정)

**실행:** <https://johnhwang20221847.github.io/robot-face-sphere/> 를 Chrome으로 열고 카메라 권한을 허용하세요. (로컬에서는 `시작.command` 더블클릭)

모든 표정은 같은 템플릿(링 눈 + 눈썹 + 눈꺼풀)에서 값만 바뀝니다.

| 단계 | 내용 |
|---|---|
| 1 | 대기 — 대상이 없으면 두리번거림 (다양한 표정·모션 연기) |
| 2 | 대상 인식 — 한쪽 눈을 찡그리고 반대쪽 눈썹을 치켜든 의심의 눈초리로 시선을 따라감 (멈춰 서면 환호) |
| 3 | 계속 움직임 — 눈이 휘둥그레 커졌다가 작아지며 화남 표정으로 |
| 4 | 계속 움직임 — 화남 표정이 화면에 꽉 찰 때까지 커짐 (이후 크기 고정, 부들부들 떨림 유지) |

각 단계가 끝나면(멈춰 서기) 그 감상자는 무시하고 두리번거리며 새 감상자를 찾고, 새 감상자가 인식되면 처음부터 다시 진행합니다.

**단축키:** `D` 디버그 화면 · `M` 좌우 반전 · `F` 전체화면 · `1` 대기 · `2` 찡그림 · `3` 놀람→화남 · `4` 커짐 · `5` 환호 · `6~9` 대기 연기 미리보기 · `0` 자동

사람 인식: [MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker) (오프라인 동작을 위해 라이브러리·모델 포함)
